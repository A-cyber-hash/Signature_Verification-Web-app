## 🚀 Quick Commands

### Setup Backend (One Time)
```bash
python setup_backend.py
```

### Start Backend
```bash
cd backend
source venv/bin/activate
python manage.py runserver
```

### Start Frontend
```bash
cd frontend
npm run dev
```

### Run Both
```bash
bash run.sh
```
