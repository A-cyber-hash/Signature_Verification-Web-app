# 📱 Mobile App - Quick Start Guide

## 🚀 Access Mobile App (30 seconds)

### Step 1: Start Backend
```bash
cd backend
python manage.py runserver
```

### Step 2: Start Frontend
```bash
cd frontend
npm run dev
```

### Step 3: Open Mobile App
```
URL: http://localhost:5173/mobile
```

## 📷 Camera System (Verification Tab)

### How to Use

1. **Click "Open Camera"**
   - Camera opens
   - Shows live video feed

2. **Take Photo**
   - Click "Take Photo" button
   - Photo captured
   - Preview dialog opens

3. **Flip Camera** (Optional)
   - Click flip icon
   - Switches front/back camera

4. **Verify with AI**
   - Click "Verify Now"
   - AI processes (2 seconds)
   - Results display

### AI Results Show
- ✅ Genuine or ✗ Forged
- Confidence Score (%)
- Quality Score (%)
- Feature Analysis:
  - Pressure
  - Speed
  - Angle

### Retake
- Click "Retake" to capture again

---

## 🤖 AI Chatbot (Chat Support Tab)

### How to Use

1. **See Suggestions**
   - 5 AI suggestions appear
   - Click any suggestion

2. **Or Type Message**
   - Type in message field
   - Press Enter or click Send
   - AI responds automatically

### Available Suggestions
- Verify Your Signature
- Upload Multiple Signatures
- View Verification History
- How accurate is the system?
- What is genuine signature?

### Features
- Message history
- Typing animation
- Timestamps
- Auto-responses

### Method 1: Settings Tab

### Method 2: Top App Bar
1. Click **Language icon** (top right)
2. Select language in dialog
3. Click confirm

### What Changes
- All text updates
- Button labels change
- Chatbot responses change
- Language persists

## 🚨 Troubleshooting

### Camera Not Working
```
1. Check browser permissions
2. Allow camera access
3. Refresh page
4. Try different browser
```

### Language Not Changing
```
1. Clear browser cache
2. Clear localStorage
3. Refresh page
4. Try again
```

### Chatbot Not Responding
```
1. Check console (F12)
2. Verify internet connection
3. Refresh page
4. Try different message
```

### Mobile View Issues
```
1. Resize browser window
2. Check responsive design
3. Test on actual mobile
4. Clear cache
```
